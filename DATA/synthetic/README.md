# Synthetic inputs

`supply_daily.csv` and `demand_decadal.csv` have the structure of the processed operating records of the Kegeyli
irrigation system, but their values are generated by `scripts/make_synthetic_inputs.py` (seed 7). They make it possible
to run the tests, the demonstration runs and the graphical interface without the records, which are third-party data
and are not part of this repository.

- `supply_daily.csv`: daily head discharge `kegeyli_Q`, m³/s, 1 April–30 September 2010–2019; blank cells mark days
  without a record, as in the original data.
- `demand_decadal.csv`: decadal demand at the Dustlik node for the demand variants A, B and C; the seasonal volume of
  each outlet equals the value in Table S3 of the Supplementary Materials.

Results computed with these files are not the results of the article. The stored results in `results/` were computed
with the operating records; their checksums are recorded in every `.meta.json` file.
